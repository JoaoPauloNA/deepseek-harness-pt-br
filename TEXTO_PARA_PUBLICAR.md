## Título

DeepSeek Harness em Português do Brasil (pt-BR)

## Texto

Publiquei a primeira versão do **DeepSeek Harness — Português do Brasil**.

O projeto adiciona suporte a `pt-BR` à interface Web do DeepSeek Harness e organiza as traduções como um pacote de idioma separado, sem alterar componentes visuais, estilos ou dados das sessões.

Nesta versão inicial, os fluxos de conversa, espaços de trabalho e metas já contam com tradução. As demais telas seguem com fallback em inglês enquanto a cobertura é ampliada.

O repositório inclui um guia para instalar, iniciar e testar localmente, além de uma issue pública que acompanha as áreas restantes da interface.

Repositório: https://github.com/JoaoPauloNA/deepseek-harness-pt-br

Contribuições para revisar traduções e cobrir novos namespaces são bem-vindas.
